3. Fonction successfullCaptcha — code extrait du bundle (419KB)

function successfullCaptcha(n) {
    // Cache le widget et affiche un spinner
    document.querySelector("#captchaText").style.display = "none";
    document.querySelector("#captchaDiv").style.display  = "none";
    document.querySelector("#loader").style.display      = "block";
    document.querySelector("#loaderText").style.display  = "block";
    // POST le token vers le serveur
    SharedAjaxService.setCaptchaToken(ajaxUrl, { captcha: n }, function(n) {
        setupSessionTimeout(n.validUntil, n.redirectUrl);
        location.href = n.redirectUrl;   // redirect immédiat vers la page de créneaux
    });
}

4. SharedAjaxService — définition complète extraite

SharedAjaxService = function() {
    // GET générique
    function get(url, data, ok, err) {
        return $.ajax({ url, type: "GET", cache: false, traditional: true, data, success: ok, error: err || console.error });
    }
    // POST générique (traditional: true = form-encoded, PAS JSON)
    function post(url, data, ok, err) {
        return $.ajax({ url, type: "POST", cache: false, traditional: true, data, success: ok, error: err || console.error });
    }
    const CAPTCHA_ENDPOINT  = "Captcha/SetCaptchaToken";
    const CANCEL_ENDPOINT   = "Shared/DoCancelRequestAppointment";
    return {
        ajaxGet:                get,
        ajaxPost:               post,
        setCaptchaToken:        (base, data, ok, err) => post(base + CAPTCHA_ENDPOINT, data, ok, err),
        appointmentCancelRequest:(base, data, ok, err) => post(base + CANCEL_ENDPOINT,  data, ok, err),
    };
}();

Point critique : traditional: true → le body est form-encoded (captcha=TOKEN), pas JSON.
5. Requête HTTP exacte vers SetCaptchaToken

POST https://appointment.cloud.diplomatie.be/Captcha/SetCaptchaToken
Cookie: ASP.NET_SessionId=<valeur>
Content-Type: application/x-www-form-urlencoded
captcha=<token-hcaptcha>

Pas de CSRF token — confirmé : la route n'exige pas __RequestVerificationToken.

7. Timer de session — setupSessionTimeout

function convertLocalTimeToUTC() {
    const n = new Date();
    return new Date(n.getTime() + n.getTimezoneOffset() * 60000);
}
function getValidUntilMilliseconds(validUntil) {
    const now = convertLocalTimeToUTC();
    const exp = new Date(validUntil);
    return exp.getTime() - now.getTime();   // durée restante en ms
}
function setupSessionTimeout(validUntil, redirectUrl) {
    const ms = getValidUntilMilliseconds(validUntil);
    setTimeout(() => { location.href = redirectUrl ?? location.href; }, ms);
}

Ce que ça signifie pour le bot : validUntil est un ISO datetime UTC. La session dure typiquement ~15-30 min. Le bot doit relancer SetCaptchaToken (nouveau hCaptcha) avant l'expiration pour garder la session vivante.
8. Polling créneaux — /Home/AvailableTimeSlots

function callPost(url, data, ok, err) {
    $.ajax({
        url, type: "Post", cache: false,
        contentType: "application/json",     // ← JSON ici (différent de SetCaptchaToken)
        dataType: "json",
        data: JSON.stringify(data),
        success: ok, error: err
    });
}
function getAvailableTimeSlotsForPublic(baseUrl, data, ok, err) {
    callPost("/Home/AvailableTimeSlots", data, ok, err);
}

Ce que ça signifie pour le bot : POST /Home/AvailableTimeSlots avec body JSON {} (body vide), Content-Type: application/json, cookie ASP.NET_SessionId requis.

10. VOWINT login — Captcha requis ?

La page de login VOWINT charge le script hCaptcha (js.hcaptcha.com/1/api.js) mais le formulaire HTML ne contient pas de widget captcha visible — juste UserName, Password, __RequestVerificationToken. Le captcha VOWINT n'est probablement déclenché qu'après des échecs répétés (lockout progressif), pas au premier login.
Résumé pour le bot — ce qu'il faut implémenter correctement
Étape	Endpoint	Content-Type	Cookie requis
Résoudre hCaptcha	POST /Captcha/SetCaptchaToken	application/x-www-form-urlencoded	ASP.NET_SessionId
Vérifier créneaux	POST /Home/AvailableTimeSlots	application/json	ASP.NET_SessionId
Annuler RDV	POST /Shared/DoCancelRequestAppointment	application/x-www-form-urlencoded	ASP.NET_SessionId

Le bot actuel dans cevPortal.ts fait déjà correctement le POST form-encoded pour SetCaptchaToken. La logique de validUntil est maintenant claire : c'est un datetime ISO UTC, et la session dure typiquement 15 minutes (defaultTimeout: 15 mentionné dans les logs précédents).
