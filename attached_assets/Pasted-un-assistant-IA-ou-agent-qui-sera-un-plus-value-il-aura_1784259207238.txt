🤖 Plan — Agent commercial IA "Joventy Sales AI"
Concept & persona
Nom : Victor (conseiller en immigration, 60 ans d'expérience) Rôle unique : convertir les visiteurs en clients. Pas un chatbot généraliste — un vendeur de haut niveau qui connaît chaque page, chaque objection, et chaque profil de visiteur. Posture : confiant, chaleureux, direct, jamais vague. Il rassure, légitime, et pousse à l'action concrète à chaque échange.

Architecture technique
Visiteur (React)
    │  message + { page, sessionId, isAuth, userContext }
    ▼
Convex HTTP Action  /api/chat
    ├── Rate limiter  (table chatSessions — 5 msg/min, 30 msg/h par session)
    ├── System prompt builder  (injecte le contexte page + profil)
    └── AWS Bedrock  amazon.nova-lite-v2:0
            ▼
        Réponse streamée → widget React

3 couches du plan
Couche 1 — Backend Convex (convex/chatAction.ts)
Composant	Détail
Endpoint	httpAction POST /api/chat
Rate limiting	Table chatSessions : sessionId, messageCount, windowStart → max 5/min, 30/h
AWS Bedrock	@aws-sdk/client-bedrock-runtime · InvokeModelCommand · modèle amazon.nova-lite-v2:0
Credentials	AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, AWS_REGION stockés dans Convex env vars
System prompt	Dynamique : persona fixe + contexte page injecté à chaque appel
Couche 2 — System prompt (persona + contexte page)
Chaque page envoie son pageContext. Victor adapte son discours :

Page	Focus Victor
/ Landing	Accueil, question de qualification, push vers prix ou prise de contact
/prix	Gérer l'objection prix, montrer le ROI, pousser vers inscription
/audit-diagnostic	Qualifier le besoin, démontrer l'expertise, CTA audit
/guides/*	Éduquer → créer l'envie → rediriger vers service
/dashboard (connecté)	Compléter le dossier en cours, prochaine étape concrète
/dashboard/contrat	Urgence : signer maintenant, expliquer les risques sans signature
/ambassades/*	Contextualiser l'ambassade visée, push consultation
Couche 3 — Widget React (ChatWidget.tsx)
Feature	Comportement
Auto-déclenchement	Apparaît après 15s sur landing, 8s sur /prix, immédiat sur /dashboard/contrat
Message d'ouverture	Personnalisé selon la page (pas "Bonjour, puis-je vous aider ?")
Session persistante	sessionId en localStorage pour mémoire cross-page
Indicateur de frappe	Dots animés pendant l'appel Bedrock
CTA intégrés	Victor peut proposer des boutons cliquables : "Voir les tarifs", "Commencer mon dossier", "Prendre RDV"
Mobile-first	Sheet bottom sur mobile, bubble fixe sur desktop
Rate limiting — règles
Par sessionId (localStorage UUID) :
  • 5 messages / minute   → réponse douce : "Laissez-moi un instant…"
  • 30 messages / heure   → "Passons à l'étape suivante, un conseiller humain va vous contacter"
  • Pas de stockage IP (RGPD)

Messages d'ouverture Victor selon page
Landing : "Bonjour ! Je suis Victor, conseiller Joventy. En 30 secondes, dites-moi : pour quel pays souhaitez-vous un visa ?"
Prix : "Je vois que vous comparez nos formules. Ce qui fait la différence ici, c'est le taux d'acceptation — 94 %. Quelle destination vous intéresse ?"
Dashboard/contrat : "Votre contrat n'est pas encore signé. C'est la seule chose qui bloque le démarrage de votre dossier. Voulez-vous que je vous guide en 2 minutes ?"
Utilisateur connecté sans dossier : "Bienvenue ! Votre compte est prêt. Il ne manque plus que votre dossier pour commencer. Par où souhaitez-vous partir ?"
