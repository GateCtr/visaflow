Le passage à dataType: 'text' (XHR) a tout cassé — le serveur ne répond qu'aux requêtes de type script tag (pas d'X-Requested-With, pas d'Accept custom). Il faut revenir à un script tag manuel, mais gérer le callback= prefix du serveur.

La solution : injecter un <script> tag nous-mêmes avec un callback fixe. Le serveur retourne callback=cbName(data) — côté JS, callback=cbName(data) est une assignation qui appelle cbName(data). Il suffit de prédéclarer window.callback comme variable pour éviter le ReferenceError.
Le timeout à 27B révèle le problème : notre callback __bkt_XXX ne commence pas par jQuery — le serveur Bookitit valide ce préfixe et retourne une réponse vide/incorrecte (les 27B sont probablement callback=__bkt_xxx() sans données). Il faut que le nom commence par jQuery.
