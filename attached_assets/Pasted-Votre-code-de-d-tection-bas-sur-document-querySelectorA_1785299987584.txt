Votre code de détection basé sur `document.querySelectorAll("iframe")` échoue pour **deux raisons fondamentales** spécifiques à l'architecture de Cloudflare Turnstile / Managed Challenge :

---

### 1. Le widget Turnstile est encapsulé dans le Shadow DOM

Lorsque Cloudflare injecte le widget Turnstile/Challenge (ex: le bouton de vérification), il n'ajoute pas l'iframe directement dans le `document` principal. Il utilise la technologie Web Components et le **Shadow DOM fermé (Closed Shadow Root)** via une balise hôte comme `<div id="cf-turnstile">` ou `<div class="cf-turnstile">`.

Comme `document.querySelectorAll("iframe")` ne traverse pas les racines Shadow DOM (`shadowRoot`), vos requêtes dans le document principal retournent une liste vide (`iframes.length === 0`).

### 2. Le défi est généré dynamiquement dans une Iframe isolée sans attribut `src` initial

Certains scripts Managed Challenge créent une iframe dynamique en mémoire (`about:blank` ou `blob:...`) puis injectent le code HTML/JS dedans à la volée. Si votre code cherche immédiatement `f.src.includes("challenges.cloudflare.com")`, la propriété `src` est soit vide `""`, soit égale à un lien `blob:[https://www.citaconsular.es/](https://www.citaconsular.es/)...` (ce que vos logs confirment : `GET blob:https://...`).

---

### Solution : Comment détecter le Widget correctement (Puppeteer / Playwright)

#### Option A : Traverser le DOM en profondeur (Deep DOM Traversal & CDP)

Pour trouver les iframes même nichées dans des Shadow DOM ou créées dynamiquement, il faut inspecter le cadre (`frame`) directement au niveau du protocole du navigateur plutôt que par le DOM standard :

```typescript
// En Puppeteer / Playwright, interrogez les objets "Frame" de la page :
const frames = page.frames();

const cfFrame = frames.find(frame => {
  const url = frame.url();
  const name = frame.name();
  return (
    url.includes("challenges.cloudflare.com") ||
    url.includes("cdn-cgi/challenge-platform") ||
    url.startsWith("blob:") ||
    name.includes("cf-")
  );
});

if (cfFrame) {
  console.log("Iframe Cloudflare trouvée :", cfFrame.url());
}

```

#### Option B : Cibler le conteneur Turnstile dans le DOM

Si vous souhaitez interagir avec l'élément visuel depuis la page racine, cherchez les conteneurs connus de Cloudflare avant de chercher l'iframe :

```typescript
const isWidgetPresent = await page.evaluate(() => {
  // 1. Recherche par sélecteurs standard Cloudflare Turnstile
  const selectors = [
    '#cf-turnstile',
    '.cf-turnstile',
    'iframe[src*="challenges.cloudflare.com"]',
    'iframe[src*="cdn-cgi"]',
    'div[class*="cf-"]'
  ];

  for (const selector of selectors) {
    if (document.querySelector(selector)) return true;
  }

  // 2. Traversée manuelle du Shadow DOM si présent
  const shadowHosts = document.querySelectorAll('*');
  for (const host of Array.from(shadowHosts)) {
    if (host.shadowRoot) {
      const shadowIframe = host.shadowRoot.querySelector('iframe');
      if (shadowIframe) return true;
    }
  }

  return false;
});

```
