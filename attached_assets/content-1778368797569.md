# Getting Started

You can learn how to use CapSolver services by following these steps

## Step. 1: Create Account [Permalink for this section](https://docs.capsolver.com/en/guide/getting-started/\#step-1-create-account)

Before you are ready to use [CapSolver’s services](https://dashboard.capsolver.com/), you need to go to the user panel
and register your account. There are
many ways to [register](https://dashboard.capsolver.com/). If you don’t see the way you want to register, please contact
us.

## Step. 2: Get your API Key [Permalink for this section](https://docs.capsolver.com/en/guide/getting-started/\#step-2-get-your-api-key)

Once you have registered, you can obtain your api key from the home page panel.
![img.png](https://docs.capsolver.com/_next/image/?url=%2F_next%2Fstatic%2Fmedia%2Fhow-to-copy-apikey.aed60361.png&w=1920&q=75)

## Step. 3: Create Task [Permalink for this section](https://docs.capsolver.com/en/guide/getting-started/\#step-3-create-task)

When you have the key ready, you can create the task using our API method [createTask](https://docs.capsolver.com/en/guide/api-createtask/). Here is an
example of the parameters of a http request.

```
POST https://api.capsolver.com/createTask
Host: api.capsolver.com
Content-Type: application/json
```

```
{
  "clientKey": "YOUR_API_KEY",
  "task": {
    "type": "ReCaptchaV2TaskProxyLess",
    "websiteURL": "https://www.google.com/recaptcha/api2/demo",
    "websiteKey": "6Le-wvkSAAAAAPBMRTvw0Q4Muexq9bi0DJwx_mJ-",
    "cookies": "cookiename=1;cookiename=2;cookieName=3"
  }
}
```

When your account has sent a request with sufficient balance and correct parameters, you will receive the following
api response.

```
{
  "errorId": 0,
  "errorCode": "",
  "errorDescription": "",
  // Make a note of this ID, which will be used in subsequent query results
  "taskId": "61138bb6-19fb-11ec-a9c8-0242ac110006"
}
```

We currently support various types of tasks. You can use the parameter `task > type` to distinguish task types

- Task (Recognition)
  - [ImageToTextTask](https://docs.capsolver.com/en/guide/recognition/ImageToTextTask/)
  - [reCAPTCHA v2](https://docs.capsolver.com/en/guide/recognition/ReCaptchaClassification/)
  - [AWS WAF](https://docs.capsolver.com/en/guide/recognition/AwsWafClassification/)
  - [VisionEngine](https://docs.capsolver.com/en/guide/recognition/VisionEngine/)
- Task (Token)
  - [GeeTest](https://docs.capsolver.com/en/guide/captcha/Geetest/)
  - [reCAPTCHA v2](https://docs.capsolver.com/en/guide/captcha/ReCaptchaV2/)
  - [reCAPTCHA v3](https://docs.capsolver.com/en/guide/captcha/ReCaptchaV3/)
  - [MTCaptcha](https://docs.capsolver.com/en/guide/captcha/MtCaptcha/)
  - [DataDome](https://docs.capsolver.com/en/guide/captcha/datadome/)
  - [AWS WAF](https://docs.capsolver.com/en/guide/captcha/awsWaf/)
  - [Cloudflare Turnstile](https://docs.capsolver.com/en/guide/captcha/cloudflare_turnstile/)
  - [Cloudflare Challenge](https://docs.capsolver.com/en/guide/captcha/cloudflare_challenge/)

## Step. 4: Get Task Result [Permalink for this section](https://docs.capsolver.com/en/guide/getting-started/\#step-4-get-task-result)

Usually [Identify task](https://docs.capsolver.com/en/guide/api-tasktype/) returns the result directly via [createTask](https://docs.capsolver.com/en/guide/api-createtask/)
But [task token](https://docs.capsolver.com/en/guide/api-tasktype/) takes more time, so you need to go through [getTaskResult](https://docs.capsolver.com/en/guide/api-gettaskresult/)
separately.
Obtain the task result.

```
headers

POST https://api.capsolver.com/getTaskResult
Host: api.capsolver.com
Content-Type: application/json
```

```
{
  "clientKey": "YOUR_API_KEY",
  //The result returned by the first step createTask
  "taskId": "37223a89-06ed-442c-a0b8-22067b79c5b4"
}
```

Generally just wait for ‘1-10s’ and you will get the result of the task execution
via [getTaskResult](https://docs.capsolver.com/en/guide/api-gettaskresult/). The following is a successful response
When a request is sent with sufficient balance and correct parameters in your account, you will get the following api
response

```
{
  "errorId": 0,
  "solution": {
    "userAgent": "xxx",
    "gRecaptchaResponse": "03AGdBq25SxXT-pmSeBXjzScW-EiocHwwpwqtk1QXlJnGnUJCZrgjwLLdt7cb0..."
  },
  "status": "ready"
}
```
